# לארג’ פעמי – אפליקציית Android (Capacitor)

זהו פרויקט Android אמיתי: Capacitor עוטף את ממשק האפליקציה הקיימת (HTML/JS) באפליקציה מותקנת עם WebView של המערכת, ללא דפדפן וללא Claude. הקוד לא נכתב מחדש ב-Kotlin, וממשק המסכים נשאר אותו ממשק.

## 0. גיבוי הנתונים הקיימים (חובה לפני כל מעבר)
באפליקציה הנוכחית: ⚙ נתונים ← "הצג גיבוי להעתקה" או "הורד קובץ גיבוי". שמור במייל או בהערות. הגיבוי כולל נתונים בלבד, בלי תמונות החשבוניות.

## עדכון מעל הגרסה המותקנת (גרסה 1.1)
- מזהה האפליקציה (com.largepami.finance) והמפתח keystore/debug.keystore לא שונו. חובה להשתמש באותו keystore ובאותו מזהה, אחרת האנדרואיד יסרב לעדכן מעל הגרסה הקיימת.
- בנה מחדש באותה דרך (GitHub Actions). מספר הגרסה עולה ל-2 אוטומטית.
- **לפני ההתקנה:** פתח את האפליקציה הנוכחית ← ⚙ נתונים ← "הורד קובץ גיבוי" ושמור אותו מחוץ למכשיר (Drive/מייל). רק אז התקן את ה-APK החדש מעל הישן. אל תסיר את הישנה.
- בהפעלה הראשונה האפליקציה שומרת עותק של המבנה הישן (large-pami-v1-v1-copy) ומשדרגת את מבנה הנתונים בלי לשנות רשומות.

## גרסה 1.3 – מה חדש בבנייה
- נוספה תוסף Android קטן (android-plugin/SaveFilePlugin.java) לשמירת גיבוי ישירות במכשיר דרך חלון "שמירה בשם" של אנדרואיד. הקוד לא עבר קומפילציה בסביבת הפיתוח שלי.
- אם ההידור של התוסף נכשל, ה-workflow בונה אוטומטית גרסה בלי התוסף (הגיבוי ימשיך לעבוד דרך חלון שיתוף) ומציג אזהרה צהובה בדף ההרצה. בדוק בסוף ההרצה אם הופיעה האזהרה.
- מספר הגרסה הוא 3. מזהה האפליקציה והמפתח לא שונו.

## 1. יצירת ה-APK בחינם (GitHub Actions, בלי להתקין כלום במחשב)
1. פתח חשבון חינמי ב-github.com וצור מאגר **פרטי** (Private) חדש.
2. העלה אליו את כל תוכן התיקייה (כולל התיקייה הנסתרת .github ואת keystore). ניתן דרך Add file ← Upload files.
3. לשונית Actions ← "Build APK" ← Run workflow. הבנייה אורכת כמה דקות.
4. בסיום, בתחתית דף ההרצה, הורד את large-pami-apk ← חלץ את app-debug.apk.
(אפשר גם לבנות ב-Android Studio החינמי: npm install, node scripts/prepare.js, npx cap add android, bash scripts/patch-android.sh, npx cap sync android, ואז Build APK.)

## 2. התקנה
העבר את ה-APK לטלפון (כבל, דרייב, מייל), פתח אותו ב"קבצים" ואשר "התקנה ממקורות לא ידועים" עבור אפליקציית הקבצים.

## 3. העברת הנתונים
האפליקציה המותקנת מתחילה ריקה (עם נתוני דוגמה). פתח ⚙ נתונים, הדבק את הגיבוי ולחץ "שחזר מהתיבה", או בחר "שחזר מקובץ".

## חשוב
- שמור את keystore/debug.keystore ואל תחליף אותו: אותו מפתח נדרש כדי שגרסאות עתידיות יתעדכנו מעל הקיימת בלי למחוק נתונים.
- הנתונים נשמרים בזיכרון האפליקציה. הם נשמרים בעדכון, ונמחקים בהסרת האפליקציה או ב"נקה נתונים". אין שמירה בענן, לכן יש לגבות.
- ייצוא גיבוי ותבניות Excel נפתחים בחלון שיתוף של אנדרואיד (שמירה ל-Drive/קבצים, מייל וכו').
- נדרש Android System WebView במכשיר (רכיב מערכת, קיים כמעט תמיד, אינו דפדפן).

## גרסה 2.0 – בנייה מחדש
- ממשק חדש לגמרי: כפתור הוספה אחד עם אשף שלבים, מסך בית חדש, הכנסות והוצאות עם כרטיסים, כרטסת, דוחות ו-PDF, ייבוא אקסל אחד, אשף קטגוריה חדשה והגדרות.
- מספר הגרסה עלה ל-4 (2.0). מזהה האפליקציה והמפתח לא שונו, כך שההתקנה מעדכנת מעל הישנה.
- בפתיחה הראשונה האפליקציה מזהה את הנתונים הישנים, מציגה בדיקת התאמה (מספרים וסכומים לפני ואחרי) וממירה רק אחרי אישור. הנתונים הישנים לא נמחקים.
- גיבויים מהגרסאות הישנות (מבנה 1 ו-2) נקראים ועוברים אותה המרה.
- נוסף הרכיב @capacitor/app לכפתור החזרה של אנדרואיד. הבנייה ב-GitHub מתקינה אותו אוטומטית.
